# 使用指南

不需要注册、不需要登录，打开网页就能看和下载。这一页只讲三件事：**怎么找、怎么看、怎么下载**。

## 1. 找到你的课 { #find }

### 方法一：打开课程索引（推荐）

首页点 **开始找资料**，或顶部点 **课程索引**。

一页列出所有有资料的课程，点课程名展开文件列表，点「下载」就能取文件。

### 方法二：按学院找

首页的 **学院直达** 表，按 `00`～`07` 分成 8 类，点进去就是对应该分类的课程。

### 方法三：搜课程名

- **电脑**：在课程索引页按 ++ctrl+f++，输入课程名，例如 `高等数学`。
- **手机**：浏览器菜单里找「在页面中查找」，输入课程名。
- **本站搜索**：点右上角的搜索框，输入课程名或文件名。

!!! tip "搜不到就换个词"
    “高数”和“高等数学”是两个词，试试只输两三个字。

## 2. 在线看 { #view }

- **PDF、图片**：点「预览」或下载后看，手机上建议先下载再看。
- **`.docx` / `.pptx` / `.zip`**：浏览器打不开，需要下载后用 Office、WPS 或解压软件打开。
- PDF 加载很慢：直接下载，不要在线等。

## 3. 下载 { #download }

### 单个文件

在课程索引里展开课程，点表格里的 **下载**。

文件直接从本站下载，不需要登录 GitHub。

### 大文件

标着 **GitHub 大文件** 的，超过 24 MB，本站不托管，点了会跳到 GitHub 仓库，在那边点下载按钮。

### 手机上

- 点「下载」后如果没反应，**长按**「下载」→ 选「在新标签页打开」；
- 大文件（10 MB 以上）建议用电脑下载后再传手机。

## 4. 资料多久更新一次 { #update }

维护者上传资料后，网站会自动重新构建，一般 **5 分钟内** 就能看到新内容。

如果刚上传就打开没看到，等几分钟再刷新（++ctrl+f5++ 强制刷新）。

## 5. 找不到资料怎么办 { #help }

说明这门课还没人上传。可以：

1. 到 [Issues](https://github.com/lastwejust/Learning-in-AAU/issues) 发一条求助；
2. 或发邮件到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)。

!!! danger "考试期间别求题"
    正在进行的考试、补考、缓考题目和答案，一律不要索要。

## 打不开网站怎么办

本站有两个地址，任意一个能打开就行：

- <https://ahau-course.pages.dev/>（推荐）
- <https://lastwejust.github.io/Learning-in-AAU/>

都打不开时：换个网络（流量 / 校园网互换）再试，或发邮件说明你要的课程。

!!! note "关于 GitHub"
    资料同步存放在 GitHub 仓库，适合会用的同学。在 GitHub 上怎么浏览、怎么投稿，见仓库里的 `README.md`，这里不展开。
