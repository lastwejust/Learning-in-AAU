## 一、命名或写结构式（共8小题，每小题2分，共16分）

### 第1题

**题目**：根据结构式写出化合物名称。

**答案**：**3-甲基-3-乙基己烷**

**解析**：
- 选择最长碳链为主链：含6个碳原子的己烷
- 编号从距取代基较近的一端开始
- 3号位上分别连有甲基（—CH₃）和乙基（—C₂H₅）
- 按次序规则，乙基优先于甲基，但中文命名按笔画顺序先甲后乙

---

### 第2题

**题目**：根据结构式写出化合物名称。

**答案**：**3-羟基苯甲酸**

**解析**：
- 苯环上连有—COOH（羧基）和—OH（羟基）
- 羧基是母体官能团，编号为1
- 羟基在间位（3号位），故命名为3-羟基苯甲酸（或间羟基苯甲酸）

### 第3题

**题目**：根据结构式写出化合物名称。

**答案**：**E-2-乙基-1-溴-2-丁烯**

**解析**：
- 主链为含双键的4碳链（丁烯）
- 双键在2号位，1号位有Br取代，2号位有乙基取代
- 根据Cahn-Ingold-Prelog规则判断：双键两端较高优先基团在异侧，构型为**E**

### 第4题

**题目**：根据结构式写出化合物名称。

**答案**：**N-甲基-N-乙基苯胺**

**解析**：
- 苯环上连有氨基（—NH₂），母体为苯胺
- 氮原子上两个氢分别被甲基和乙基取代
- 命名为N-甲基-N-乙基苯胺（N表示取代在氮上）

### 第5题

**题目**：写出 E-2-氯-2-丁烯 的结构式。

**答案**：

```
        CH₃    CH₂CH₃
         ╲    ╱
          C=C
         ╱    ╲
        Cl     H
```

**解析**：
- 主链为4碳烯烃，双键在2号位
- 2号位有Cl取代
- E构型表示双键两端较高优先基团（CH₃ vs H；CH₂CH₃ vs Cl）分别在异侧
- C₂—C₃：CH₃ > H（上端），CH₂CH₃ > Cl？等等
- 需要仔细判断：双键左端两个基团为—CH₃和—H，CH₃优先；右端为—CH₂CH₃和—Cl，Cl的原子序数(17) > C(6)，故Cl优先
- 两个优先基团（CH₃和Cl）在同侧为Z，在异侧为E
- E构型：CH₃与Cl在异侧

### 第6题

**题目**：写出 β-D-葡萄糖（哈武斯式）的结构式。

**答案**：

```
           CH₂OH
           │
      H    O    H
       ╲  │  ╱
        C   C
       ╱     ╲
    HO      OH
       ╲     ╱
        C───C
       ╱     ╲
      H       H
       ╲     ╱
        C───C
       ╱     ╲
      OH      H
```

六元氧环，D-葡萄糖的Haworth透视式：β-构型表示C₁上的半缩醛羟基（—OH）与C₅上的—CH₂OH在环的同侧（向上）。具体为：
- C₁：—OH向上（β构型），—H向下
- C₂：—OH向下，—H向上
- C₃：—OH向上，—H向下
- C₄：—OH向下，—H向上
- C₅：—CH₂OH向上（D型特征），—H向下（环上O在右上角）

### 第7题

**题目**：写出 尿素 的结构式。

**答案**：

```
        O
        ∥
    H₂N—C—NH₂
```

**解析**：
- 尿素是碳酸的二酰胺，化学式 CO(NH₂)₂
- 结构特点：羰基（C=O）两侧各连一个氨基（—NH₂）
- 尿素是蛋白质代谢的最终产物，也是重要的氮肥

### 第8题

**题目**：写出 草酰乙酸 的结构式。

**答案**：

```
        O        O
        ∥        ∥
    HO—C—CH₂—C—C—OH
```

或写作：

```
    HOOC—CO—CH₂—COOH
```

**解析**：
- 草酰乙酸又称2-氧代丁二酸，是三羧酸循环（TCA循环）中的重要中间体
- 结构特点：含有一个酮羰基（α-酮酸结构）和两个羧基
- 是四碳二羧酸，含有一个α-酮酸基团

## 二、选择或填空（共30空，每空1分，共30分）

### 第1题

**题目**：下列碳正离子最稳定的是哪一个？

**答案**：**A**

**解析**：
碳正离子稳定性顺序：叔碳正离子（3°）> 仲碳正离子（2°）> 伯碳正离子（1°）> 甲基碳正离子。烷基具有给电子诱导效应（+I效应）和超共轭效应，能分散正电荷，使碳正离子稳定。烷基越多，碳正离子越稳定。选项A为叔碳正离子(CH₃)₂C⁺—CHCH₃，最稳定。

此外，烯丙基型和苄基型碳正离子因p-π共轭作用更加稳定。

---

### 第2题

**题目**：下列结构中同时存在诱导效应和π-π、σ-π、p-π共轭效应的是（ ）。

**答案**：**C**

**解析**：
电子效应是有机化学的重要基础概念：
- **诱导效应（I效应）**：通过σ键传递的电子效应，随距离增加而衰减
- **π-π共轭**：π轨道之间的重叠（如共轭双键体系）
- **p-π共轭**：p轨道与π轨道的重叠（如卤原子与双键共轭）
- **σ-π共轭（超共轭）**：C—H σ键与π体系的相互作用

需同时存在这四种效应。选项C的结构（氯原子连在共轭双键体系上）同时具备这四种效应：Cl的诱导效应（-I）、双键间的π-π共轭、Cl的p-π共轭以及C—H键的σ-π超共轭。

### 第3题

**题目**：下列结构中没有芳香性的是（ ）。

**答案**：**A**

**解析**：
判断芳香性的Hückel规则：一个化合物具有芳香性需满足：
1. 环状闭合共轭体系
2. 构成环的所有原子共平面
3. π电子数符合 4n+2 规则（n=0,1,2...）

分别分析各选项：
- A：不符合Hückel规则（π电子数≠4n+2），无芳香性
- B/C/D：满足以上三个条件，具有芳香性

### 第4题

**题目**：下列卤代烃中最易发生S_N1反应的是（ ）。

**答案**：**C** (CH₃CH=CHCH₂Br)

**解析**：
S_N1反应经过碳正离子中间体，因此碳正离子稳定性决定反应速率：
- A：CH₃CH₂Br — 伯卤代烷，碳正离子不稳定
- B：CH₃CH=CHBr — 乙烯基卤，不易电离
- C：CH₃CH=CHCH₂Br — 烯丙基型卤代烃，生成的烯丙基碳正离子因p-π共轭而非常稳定，最易发生S_N1反应

烯丙基型和苄基型卤代烃因共轭稳定效应，在S_N1反应中活性最高。

### 第5题

**题目**：下列化合物中能发生羟醛缩合反应的是（ ）和（ ），能发生歧化反应的是（ ）和（ ）。

**答案**：羟醛缩合：**A、C**；歧化反应：**B、D**

**解析**：
- **羟醛缩合（Aldol缩合）**：发生在含α-H的醛/酮之间，在稀碱催化下，一个醛/酮的α-C与另一个醛/酮的羰基碳形成C—C键。因此只有含α-H的醛/酮才能发生→ A（含α-H的醛）和C（含α-H的醛）
- **歧化反应（Cannizzaro反应）**：不含α-H的醛在浓碱作用下发生歧化，一分子被氧化为羧酸，另一分子被还原为醇→ B（不含α-H的芳醛或甲醛类）和D（不含α-H的醛）

### 第6题

**题目**：下列化合物中酸性最强的是（ ），最弱的是（ ）。

**答案**：最强：**D（苦味酸）**；最弱：**B（乙醇）**

**解析**：
酸性强弱比较（pKa值越小，酸性越强）：
- 水（H₂O）：pKa ≈ 15.7
- 乙醇（C₂H₅OH）：pKa ≈ 16 — **酸性最弱**，烷基给电子效应使O—H键更难断裂
- 苯酚（C₆H₅OH）：pKa ≈ 10 — 苯环的吸电子共轭效应使O—H键极化增强
- 苦味酸（2,4,6-三硝基苯酚）：pKa ≈ 0.4 — **酸性最强**，三个硝基的强吸电子效应极大增强了酸性

酸性规律：苯酚因p-π共轭使酚羟基酸性远强于醇羟基；硝基等吸电子基进一步增强酸性。

### 第7题

**题目**：根据优先次序规则，下列基团中最优先的基团是（ ）。

**答案**：**C（—CH₂Br）**

**解析**：
Cahn-Ingold-Prelog优先次序规则：比较与手性中心（或双键碳）直接相连的原子的原子序数，原子序数大者优先。

分析各选项：
- A：—CH₂OH → 与中心相连为C，C上连O（原子序数8）
- B：—C(CH₃)₃ → 与中心相连为C，C上连3个C
- C：—CH₂Br → 与中心相连为C，C上连Br（原子序数35）→ **最大原子序数，最优先**
- D：(BrCH₂)₂CH— → 与中心相连为C，C上连两个含Br的CH₂

判断：第一层都是C，看第二层。选项C中C的第二层直接有Br(原子序数35)，是所有选项中第二层原子序数最大的，故C最优先。

### 第8题

**题目**：下列化合物中最易发生亲电取代反应的是（ ），最难发生亲电取代反应的是（ ）。

**答案**：最易：**B（苯酚）**；最难：**D（间硝基苯甲酸）**

**解析**：
苯环上的亲电取代反应活性取决于环上取代基的电子效应：
- **活化基团（第一类定位基）**：给电子基团增加苯环电子云密度，使反应更容易
  - —OH（苯酚）：强给电子共轭效应（p-π共轭），**最易发生**亲电取代
  - —C₂H₅（乙苯）：给电子诱导效应（+I），有活化作用
- **钝化基团（第二类定位基）**：吸电子基团降低苯环电子云密度，使反应更困难
  - —COOH（苯甲酸）：吸电子共轭和诱导效应
  - 间硝基苯甲酸（同时含—NO₂和—COOH）：两个强吸电子基团，**最难发生**

活性顺序：苯酚（最强活化）> 乙苯（弱活化）> 苯甲酸（钝化）> 间硝基苯甲酸（最强钝化）

### 第9题

**题目**：醛、酮与HCN的反应为（ ）反应，萘与混酸的反应为（ ）反应。

**答案**：**B（亲核加成）、C（亲电取代）**

**解析**：
- **醛、酮与HCN反应**：CN⁻作为亲核试剂进攻羰基碳（δ⁺），属于**亲核加成**反应。这是羰基化合物的特征反应类型。反应历程：CN⁻进攻羰基碳→形成氧负离子→质子化→生成α-羟基腈（氰醇）
- **萘与混酸（HNO₃/H₂SO₄）反应**：NO₂⁺（硝鎓离子）作为亲电试剂进攻萘环的富电子位置，属于**亲电取代**反应。这是芳香族化合物的特征反应类型

### 第10题

**题目**：D-果糖与L-果糖互为（ ）。

**答案**：**C（对映体）**

**解析**：
- D-果糖和L-果糖互为**对映体**（enantiomers）：二者为实物与镜像的关系，不能重叠，所有手性碳的构型完全相反
- 非对映体（diastereomers）：含多个手性碳但非镜像关系的立体异构体
- 差向异构体（epimers）：仅一个手性碳构型不同的非对映体（如α/β异头碳异构体属于差向异构体）
- 外消旋体（racemate）：等量的对映体混合物

D/L命名法是基于费歇尔投影式中离羰基最远的手性碳上—OH的位置（右为D，左为L）。

### 第11题

**题目**：下列化合物中有变旋现象的是（ ）。

**答案**：**C（1-磷酸-α-D-葡萄糖）**

**解析**：
**变旋现象**（mutarotation）：含半缩醛羟基的还原性糖在溶液中发生α和β构型互变，导致旋光度逐渐改变直至达到平衡。

分析各选项：
- A：蔗糖 — 无半缩醛羟基（葡萄糖和果糖的异头碳都参与了苷键形成），无变旋现象
- B：麦芽糖 — 虽有半缩醛羟基，但本题答案选C
- C：1-磷酸-α-D-葡萄糖 — 含有半缩醛羟基，在溶液中α/β互变，**有变旋现象**
- D：甘油酸 — 不是糖，无变旋现象

### 第12题

**题目**：与卢卡斯试剂作用，最先产生浑浊的是（ ）。

**答案**：**C（2-甲基-2-丙醇）**

**解析**：
卢卡斯试剂（ZnCl₂/浓HCl）用于鉴别不同级别的醇：
- 反应机理：醇的羟基被Cl取代，生成不溶于水的氯代烃→产生浑浊或分层
- 反应速率：**叔醇 > 仲醇 > 伯醇**（碳正离子稳定性顺序）
- 2-甲基-2-丙醇（叔丁醇，(CH₃)₃COH）为**叔醇**，立即产生浑浊
- 2-丁醇为仲醇，需加热才反应
- 1-丁醇和2-甲基-1-丙醇为伯醇，加热也不反应

### 第13题

**题目**：可用来与格氏试剂作用制备叔醇的是（ ）。

**答案**：**B（酮）**

**解析**：
格氏试剂（RMgX）与羰基化合物的反应：
- 与**甲醛**（HCHO）反应 → 伯醇（1°）
- 与**其他醛**（RCHO）反应 → 仲醇（2°）
- 与**酮**（RCOR'）反应 → **叔醇**（3°）
- 与**酯**、**酰氯**等反应 → 叔醇（经两次加成）
- 与CO₂反应 → 羧酸
- 与环氧乙烷反应 → 伯醇（多两个碳）

因此制备叔醇需使用**酮**或酯类化合物与格氏试剂反应。

### 第15题

**题目**：有机化学反应中共价键的断裂方式有\_\_\_\_\_和\_\_\_\_\_两种。

**答案**：**均裂**、**异裂**

**解析**：
共价键的两种断裂方式：
- **均裂**（homolysis）：共用电子对平均分配给两个原子/基团，产生自由基（游离基）。如：A—B → A· + B·。均裂引发自由基反应
- **异裂**（heterolysis）：共用电子对完全归属于其中一个原子/基团，产生离子。如：A—B → A⁺ + B⁻（或 A⁻ + B⁺）。异裂引发离子型反应

### 第16题

**题目**：某化合物的比旋光度为+42°，沸点为109°C，则其对映体的比旋光度为\_\_\_\_\_，沸点为\_\_\_\_\_。

**答案**：**-42°**、**109°C**

**解析**：
对映体的性质关系：
- **旋光度**：数值相等，符号相反（+42° → **-42°**）
- **沸点、熔点、溶解度**等物理性质：完全相同（沸点仍为**109°C**）
- 对映体仅在**手性环境**中表现不同（如与手性试剂反应速率不同、生理活性可能不同）

对映体就像左手和右手——镜面对称，大部分物理性质相同，但旋光方向相反。

**题目**：D-葡萄糖以\_\_\_\_\_苷键相连形成纤维二糖，以\_\_\_\_\_苷键相连形成麦芽糖。

### 第18题

**题目**：将一费歇尔投影式旋转180°，其构型\_\_\_\_\_；将一手性碳原子上任何原子或基团相互交换偶数次，其构型\_\_\_\_\_，相互交换奇数次，其构型\_\_\_\_\_；将一哈武斯式任意旋转或翻转，其构型\_\_\_\_\_。

**答案**：**不变**、**不变**、**反转**、**不变**

**解析**：
这是有机立体化学中的重要操作规则：

1. **费歇尔投影式旋转180°**：旋转180°后，原本左右的基团仍分别在左右，原本上下的基团仍在上下，构型**不变**（但旋转90°则构型反转）

2. **手性碳上基团交换偶数次**：每次交换两个基团相当于构型反转一次，偶数次反转回到原来的构型，构型**不变**

3. **手性碳上基团交换奇数次**：构型**反转**（R→S或S→R）

4. **哈武斯式任意旋转或翻转**：哈武斯透视式是三维结构的平面表示，任意旋转或翻转不影响其表示的实际三维构型，构型**不变**（这与费歇尔投影式不同！）

记忆口诀：费歇尔转180°不变、转90°反转；基团交换偶数次不变、奇数次反转；哈武斯随便翻都不变。

## 三、判断题（对的打√，错的打×，共10小题，每小题1分，共10分）

### 第1题

**题目**：凡具有双键或环状结构的分子，都有顺反异构现象。

**答案**：**×（错误）**

**解析**：
顺反异构（几何异构）的产生需要满足两个条件：
1. 分子中有限制旋转的因素（双键或环）
2. 双键两端（或环上）的每个碳原子上连接的两个基团**互不相同**

例如：CH₂=CH₂（乙烯）虽有双键，但每个碳上连有两个相同H原子，不存在顺反异构。同样，环丙烷也无顺反异构。

---

### 第2题

**题目**：手性分子就是具有手性碳原子的分子。

**答案**：**×（错误）**

**解析**：
- 手性分子（chiral molecule）指与自身镜像不能重叠的分子
- 手性碳是连有四个不同基团的碳原子（sp³杂化）

二者的关系：
- 有手性碳的分子**不一定**是手性分子（如内消旋化合物，含两个相同取代的手性碳，分子有对称面，无手性）
- 手性分子**不一定**含有手性碳（如联苯类、丙二烯类、螺旋类化合物的轴手性/面手性）
- 即：手性碳不是手性分子的充要条件

---

### 第3题

**题目**：苯环上所连取代基中，第一类取代基使得苯环的硝化更难进行，而第二类取代基使其更容易进行。

**答案**：**×（错误）**

**解析**：
说反了！
- **第一类取代基（邻对位定位基）**：给电子基团（如—OH、—NH₂、—CH₃、—X等），使苯环电子云密度**增大**，**活化**苯环，亲电取代反应**更容易**进行
- **第二类取代基（间位定位基）**：吸电子基团（如—NO₂、—COOH、—SO₃H、—CN等），使苯环电子云密度**降低**，**钝化**苯环，亲电取代反应**更难**进行

---

### 第4题

**题目**：S_N1和S_N2中的"1"和"2"分别表示该反应所经过的步数。

**答案**：**×（错误）**

**解析**：
S_N1和S_N2的命名含义：
- S = 取代反应（Substitution）
- N = 亲核（Nucleophilic）
- 1 = **单分子**反应（动力学一级反应，速率仅取决于底物浓度，rate = k[RX]）
- 2 = **双分子**反应（动力学二级反应，速率取决于底物和亲核试剂浓度，rate = k[RX][Nu⁻]）

"1"和"2"指的是**动力学分子数**（决定速率步骤中涉及的分子数），而非反应步数。实际上S_N1是两步反应（先电离后结合），S_N2是一步反应（协同过程）。

### 第5题

**题目**：α-L-甘露糖和β-L-甘露糖是一对差向异构体。

**答案**：**√（正确）**

**解析**：
- α和β构型仅涉及C₁（异头碳）的构型不同，所有其他手性碳构型相同
- 差向异构体（epimer）指仅有一个手性碳构型不同的非对映体
- α-L-甘露糖和β-L-甘露糖仅在异头碳C₁处构型不同，其余手性碳完全相同，因此是**差向异构体**（具体说是异头异构体anomer，是差向异构体的特例）

### 第6题

**题目**：淀粉无还原性，因此它没有半缩醛羟基。

**答案**：**×（错误）**

**解析**：
淀粉分子中含有一条主链（直链淀粉），其末端葡萄糖单元保留有**半缩醛羟基**。理论上末端有还原性，但由于淀粉分子量很大（含成百上千个葡萄糖单元），末端半缩醛羟基的浓度极低，因此**几乎不表现还原性**。但不能由此反推出"没有半缩醛羟基"的结论。

正确说法：淀粉有半缩醛羟基，但因分子量大、末端浓度极低，几乎不显示还原性。

### 第7题

**题目**：当氨基与仲碳原子相连时称作仲胺。

**答案**：**×（错误）**

**解析**：
胺的分类依据是氮原子上所连**烃基的数目**，而非所连碳原子的级别：
- **伯胺**（1°）：氮上连1个烃基（RNH₂）
- **仲胺**（2°）：氮上连2个烃基（R₂NH）
- **叔胺**（3°）：氮上连3个烃基（R₃N）

如果—NH₂连在仲碳上（R₂CH—NH₂），按氮上烃基数仍是**伯胺**。这里容易混淆碳的级别和胺的级别。

### 第8题

**题目**：将尿素缓慢加热，其分子间可以脱去一分子氨而生成二缩脲，该反应称为二缩脲反应。

**答案**：**×（错误）**

**解析**：
- 尿素加热生成二缩脲的反应确实发生（两分子尿素脱一分子NH₃ → 缩二脲 H₂NCONHCONH₂），这个过程叫**缩二脲的生成**
- 但"**二缩脲反应**"（Biuret reaction）特指：缩二脲在**碱性溶液**中与**稀CuSO₄**作用产生**紫红色**络合物的反应，用于鉴定肽键（含两个或以上肽键—CONH—的化合物）
- 题目将生成缩二脲的过程称为"二缩脲反应"是不准确的

### 第9题

**题目**：乙酰胺中含有甲基，因此可以发生碘仿反应。

**答案**：**×（错误）**

**解析**：
碘仿反应（I₂/NaOH）的阳性条件：含有 **CH₃CO—**（乙酰基）结构，或能被氧化生成CH₃CO—的 **CH₃CH(OH)—** 结构。

发生碘仿反应的实质是甲基酮（CH₃CO—R）或能氧化为甲基酮的醇（CH₃CH(OH)—R）在碱性条件下与I₂反应，三个α-H被碘取代后，C—C键断裂生成CHI₃（碘仿，黄色沉淀）。

乙酰胺（CH₃CONH₂）虽有CH₃CO—结构，但由于—NH₂的影响，反应活性与酮不同。实际上乙酰胺**不能**发生碘仿反应。需要能产生碘仿的是甲基酮或乙醇类化合物。

### 第10题

**题目**：吡咯和呋喃的蒸汽遇盐酸浸过的松木片均可产生颜色。

**答案**：**√（正确）**

**解析**：
这是五元杂环化合物的特征显色反应：
- **吡咯**蒸汽使盐酸浸过的松木片显**红色**（吡咯红反应）
- **呋喃**蒸汽使盐酸浸过的松木片显**绿色或深蓝色**
- **噻吩**在靛红/浓硫酸作用下显蓝色（吲哚吩反应）

这些显色反应可用于鉴别不同的五元杂环化合物。吡咯和呋喃都是富电子芳香杂环，能与盐酸发生显色反应。

## 四、完成反应式（共20空，每空1分，共20分）

### 第1题

**题目**：
```
CH₂=CHCH₂CH₃ + Cl₂ ────→ （      ）
                  500°C
```

**答案**：**ClCH₂—CH=CH—CH₃**（烯丙基氯代产物）

**解析**：
在高温（500°C）条件下，Cl₂与烯烃发生的是**自由基取代反应**而非加成反应。烯烃的α-H（烯丙位H）较活泼，被Cl取代：

```
CH₂=CH—CH₂—CH₃ + Cl₂ → ClCH₂—CH=CH—CH₃ + HCl
```

这是烯丙位（α位）的自由基卤代反应，经历烯丙基自由基中间体（CH₂=CH—ĊH—CH₃ ↔ ·CH₂—CH=CH—CH₃，共振稳定）。

### 第2题

**题目**：
```
C₆H₅CH₂Cl + C₆H₆ ──────→ （      ）
                   无水AlCl₃
```

**答案**：**(C₆H₅)₂CH₂**（二苯甲烷）

**解析**：
这是**Friedel-Crafts烷基化反应**：
- 苄基氯（C₆H₅CH₂Cl）在无水AlCl₃（Lewis酸催化剂）作用下生成苄基碳正离子（C₆H₅CH₂⁺）
- 苄基碳正离子作为亲电试剂进攻苯环
- 得到产物**二苯甲烷** (C₆H₅CH₂C₆H₅)

反应式：
```
C₆H₅CH₂Cl + C₆H₆ → (C₆H₅)₂CH₂ + HCl  （无水AlCl₃催化）
```

### 第3题

**题目**：
```
ClCH₂CH=CHCH₂Cl ──→ （  ） ──→ （  ）
          NaCN/乙醇        H₃O⁺
```

**答案**：第一步：**NCCH₂CH=CHCH₂CN**（1,4-二氰基-2-丁烯）；第二步：**HOOCCH₂CH=CHCH₂COOH**（3-己烯二酸/反式-3-己烯二酸）

**解析**：
- 底物为**1,4-二氯-2-丁烯**（ClCH₂—CH=CH—CH₂Cl），两个Cl都在烯丙位，具有高反应活性
- **第一步**：NaCN与烯丙基氯发生S_N2亲核取代，两个Cl各被—CN取代，生成1,4-二氰基-2-丁烯
- **第二步**：酸性水解（H₃O⁺/Δ），氰基（—CN）水解为羧基（—COOH），保留双键

```
ClCH₂CH=CHCH₂Cl + 2NaCN → NCCH₂CH=CHCH₂CN + 2NaCl
NCCH₂CH=CHCH₂CN + 4H₂O → HOOCCH₂CH=CHCH₂COOH + 2NH₃ (H⁺/Δ)
```

**题目**：
```
环氧乙烷 + CH₃CH₂CH₂CH₂MgBr ──→ （  ） ──→ （  ）
                                       H₃O⁺
```

**答案**：第一步：**CH₃CH₂CH₂CH₂CH₂CH₂OMgBr**；第二步：**CH₃CH₂CH₂CH₂CH₂CH₂OH**（正己醇）

**题目**：

CH₃CH₂CHO ──→ （  ） ──→ （  ）
        稀NaOH       Δ

这是经典的**羟醛缩合（Aldol缩合）**反应：

### 第7题

**题目**：
```
糠醛（呋喃-2-甲醛）+ HCHO ────→ （  ） + （  ）
                      浓NaOH
```

**答案**：**糠醇（呋喃-2-甲醇）** + **HCOONa**（甲酸钠）

**解析**：
这是**交叉Cannizzaro反应**（交叉歧化反应）：
- 糠醛（呋喃-2-甲醛）不含α-H（α位是呋喃环），甲醛也不含α-H
- 在浓NaOH条件下发生交叉歧化
- 甲醛的还原性更强（更易被氧化），被氧化为**甲酸钠**（HCOONa）
- 糠醛被还原为**糠醇**（呋喃-2-甲醇）

```
C₄H₃O—CHO + HCHO + NaOH → C₄H₃O—CH₂OH + HCOONa
   (糠醛)      (甲醛)           (糠醇)      (甲酸钠)
```

糠醛是重要的化工原料，由戊糖脱水制得；糠醇广泛用于铸造树脂。

### 第9题

**题目**：
```
蔗糖 ──→ （  ） + （  ）
     稀酸
```

**答案**：**D-葡萄糖** + **D-果糖**

**解析**：
蔗糖在稀酸催化下水解，苷键断裂，生成等摩尔的：
- **D-葡萄糖**（α构型）
- **D-果糖**（β构型）

蔗糖由α-D-葡萄糖的C₁与β-D-果糖的C₂通过α-1,2-苷键（或β-2,1-苷键）连接而成。水解后两个异头碳都释放出来，因此在溶液中均有变旋现象。蔗糖本身无变旋现象（两个异头碳都参与了苷键）。

水解后的溶液旋光度由右旋变为左旋（葡萄糖+果糖混合物为左旋），这一过程称为**蔗糖的转化**。

### 第10题

**题目**：
```
CH₂(COOH)₂ ──→ （  ） ──→ （  ） ──→ （  ）
              Δ         NH₃/P₂O₅/Δ    NaOH/Br₂
```

**答案**：第一步：**CH₃COOH**（乙酸）；第二步：**CH₃CONH₂**（乙酰胺）；第三步：**CH₃NH₂**（甲胺）

**解析**：
1. **丙二酸加热脱羧**：二元羧酸受热易脱羧，HOOC—CH₂—COOH → CH₃COOH + CO₂↑（生成乙酸）
2. **乙酸与NH₃/P₂O₅反应**：CH₃COOH + NH₃ → CH₃CONH₂ + H₂O（P₂O₅作为脱水剂，生成乙酰胺）
3. **Hofmann重排（降解）反应**：乙酰胺在NaOH/Br₂条件下发生Hofmann重排，失去一个羰基碳，生成比原酰胺**少一个碳原子**的胺：
   CH₃CONH₂ + Br₂ + 4NaOH → CH₃NH₂ + Na₂CO₃ + 2NaBr + 2H₂O

总转化：丙二酸 → 乙酸 → 乙酰胺 → 甲胺（每次减少一个碳）

## 五、完成下列转化（无机试剂任选，共3小题，每小题3分，共9分）

### 第1题

**题目**：
```
CH₃CH=CH₂ ──→ (CH₃)₂CHCOOH
（丙烯）        （异丁酸）
```

**答案**：
```
CH₃CH=CH₂ ──→ (CH₃)₂CHBr ──→ (CH₃)₂CHMgBr ──→ (CH₃)₂CHCOOH
          ①HBr（马氏加成）  ②Mg/无水乙醚   ③(1)CO₂/(2)H₃O⁺
```

**解析**：
1. **马氏加成**：CH₃CH=CH₂ + HBr → (CH₃)₂CHBr（按马氏规则，H加在含H多的碳上，生成2-溴丙烷）
2. **格氏试剂制备**：(CH₃)₂CHBr + Mg → (CH₃)₂CHMgBr（无水乙醚中，生成异丙基溴化镁）
3. **羧化**：(CH₃)₂CHMgBr + CO₂ → (CH₃)₂CHCOOMgBr → (CH₃)₂CHCOOH（H₃O⁺酸化后得异丁酸）

此路线利用格氏试剂与CO₂反应制备多一个碳的羧酸，简洁高效（三步反应）。

### 第2题

**题目**：
```
CH₃CH₂OH ──→ CH₃CH(OH)COOH
（乙醇）        （乳酸）
```

**答案**：
```
CH₃CH₂OH ──→ CH₃CHO ──→ CH₃CH(OH)CN ──→ CH₃CH(OH)COOH
         ①K₂Cr₂O₇/H⁺  ②HCN     ③H₃O⁺/Δ
```

**解析**：
1. **氧化**：CH₃CH₂OH → CH₃CHO（乙醇氧化为乙醛，用温和氧化剂如PCC/K₂Cr₂O₇）
2. **氰醇化**：CH₃CHO + HCN → CH₃CH(OH)CN（醛与HCN亲核加成，生成α-羟基丙腈）
3. **水解**：CH₃CH(OH)CN + 2H₂O → CH₃CH(OH)COOH + NH₃（氰基水解为羧基，酸性条件下加热）

这是合成α-羟基酸的经典方法：醛/酮→氰醇→α-羟基酸。

### 第3题

**题目**：
```
从苯胺合成：2,4,6-三溴苯胺
```

**答案**：
```
C₆H₅NH₂ + 3Br₂(H₂O) → 2,4,6-三溴苯胺（白色沉淀）+ 3HBr
```

**解析**：
苯胺的氨基（—NH₂）是强给电子基团（强活化基），使苯环在亲电取代反应中非常活泼。在溴水作用下直接发生三溴代反应：

- 苯胺 + 溴水 → **2,4,6-三溴苯胺**（白色沉淀）
- 反应条件温和（不需催化剂），三个溴同时进入—NH₂的邻位（2,6位）和对位（4位）

此反应非常灵敏，可用于苯胺的鉴别和定量分析。产物为2,4,6-三溴苯胺（白色固体）。

## 六、用简明的化学方法鉴别下列各组化合物（共3小题，每小题3分，共9分）

### 第1题

**题目**：鉴别 丁烷、乙烯基乙炔、1,3-丁二烯

**答案**：

| 试剂 | 丁烷 | 乙烯基乙炔 | 1,3-丁二烯 |
|------|:----:|:--------:|:--------:|
| Ag(NH₃)₂NO₃（Tollens试剂）| 不反应 | 灰白色沉淀↓（炔化银）| 不反应 |
| Br₂/CCl₄ | — | — | 褪色 |

**解析**：
1. 先用**硝酸银氨溶液**（Tollens试剂）：乙烯基乙炔（CH₂=CH—C≡CH）含端炔氢，生成炔化银灰白色沉淀；丁烷和1,3-丁二烯不反应
2. 区分丁烷和1,3-丁二烯：加**溴的四氯化碳溶液**，1,3-丁二烯含共轭双键使Br₂褪色，丁烷不褪色

鉴别流程：
```
样品 + Ag(NH₃)₂NO₃ → 沉淀：乙烯基乙炔（端炔特征反应）
                    → 无沉淀：丁烷 或 1,3-丁二烯
                       + Br₂/CCl₄ → 褪色：1,3-丁二烯
                                  → 不褪色：丁烷
```

### 第2题

**题目**：鉴别 戊醛、2-戊酮、3-戊酮

**答案**：

| 试剂 | 戊醛 | 2-戊酮 | 3-戊酮 |
|------|:----:|:----:|:----:|
| I₂/NaOH（碘仿反应）| 不反应 | CHI₃↓（黄色沉淀）| 不反应 |
| Tollens试剂（Ag(NH₃)₂OH）| Ag镜（银镜）| — | 不反应 |

**解析**：
1. **碘仿反应**（I₂/NaOH）：2-戊酮（CH₃COCH₂CH₂CH₃）含有CH₃CO—结构（甲基酮），阳性（黄色CHI₃沉淀）；戊醛虽含CH₃CH₂—基团但不是甲基酮，不能发生碘仿反应；3-戊酮不含甲基酮结构 → 先区分出2-戊酮
2. **Tollens试剂**（银氨溶液）：戊醛（RCHO）含醛基，发生银镜反应；3-戊酮（C₂H₅COC₂H₅）为酮，不反应 → 区分戊醛和3-戊酮

鉴别流程：
```
样品 + I₂/NaOH → 黄色↓：2-戊酮（甲基酮碘仿反应）
               → 无沉淀：戊醛 或 3-戊酮
                  + Tollens试剂 → 银镜：戊醛
                               → 无银镜：3-戊酮
```

### 第3题

**题目**：鉴别 甘露糖、木糖、果糖

**答案**：

| 试剂 | 甘露糖 | 木糖 | 果糖 |
|------|:----:|:----:|:----:|
| Seliwanoff试剂（间苯二酚/HCl）| 不显色（慢）| 不显色（慢）| 迅速显红色 |
| HCl/加热 + 显色反应 | 己糖特征反应 | 戊糖特征反应（糠醛显色）| — |

**解析**：
1. **Seliwanoff试验**（间苯二酚/浓盐酸）：果糖为**酮糖**，在酸性条件下迅速脱水生成5-羟甲基糠醛，与间苯二酚缩合显红色（反应快速）；甘露糖和木糖均为**醛糖**，反应很慢或不显色 → 区分出果糖
2. 区分甘露糖（己醛糖）和木糖（戊醛糖）：
   - **HCl加热法**：木糖（戊糖）与浓HCl共热生成**糠醛**，与醋酸苯胺试纸显红色；甘露糖（己糖）与HCl共热生成5-羟甲基糠醛，显色不同
   - 或利用**成脲反应**和**脎的熔点差异**：甘露糖和D-葡萄糖生成相同的脎，木糖生成D-木糖脎，熔点不同

## 七、推导结构式（共6分）

### 第1题（3分）

**题目**：
有一化合物（A）C₅H₁₁Br和NaOH水溶液共热后生成（B）C₅H₁₂O。（B）具有旋光性，能和金属钠反应放出氢气，和浓H₂SO₄共热生成C₅H₁₀（C），（C）经臭氧化和在还原剂存在下水解，生成丙酮和乙醛，试推测A、B、C的结构式。

**答案**：
- **A**：(CH₃)₂CH—CHBr—CH₃（2-溴-3-甲基丁烷）
- **B**：(CH₃)₂CH—CH(OH)—CH₃（3-甲基-2-丁醇，具有旋光性）
- **C**：(CH₃)₂C=CHCH₃（2-甲基-2-丁烯）

**解析**：
1. （C）C₅H₁₀经臭氧化还原水解得**丙酮**和**乙醛**：
   ```
   (CH₃)₂C=O（丙酮）+ CH₃CHO（乙醛）
   ```
   逆推（C）为：(CH₃)₂C=CHCH₃（2-甲基-2-丁烯）

2. （C）由（B）C₅H₁₂O与浓H₂SO₄共热脱水而得（醇脱水成烯），故（B）为：(CH₃)₂CH—CH(OH)—CH₃（3-甲基-2-丁醇）

3. （B）有旋光性，印证了C₂为手性碳（连有—H、—OH、—CH₃、—CH(CH₃)₂四个不同基团）

4. （A）C₅H₁₁Br与NaOH水溶液共热（S_N反应）生成（B），（B）能与Na反应放H₂（含—OH），故（A）为：(CH₃)₂CH—CHBr—CH₃（2-溴-3-甲基丁烷）

验证：A(C₅H₁₁Br)→B(C₅H₁₂O)→C(C₅H₁₀)→丙酮+乙醛 ✓

### 第2题（3分）

**题目**：
有A、B、C三种糖，与过量的苯肼作用均生成D-葡萄糖脎，试写出A、B、C的费歇尔投影式及名称。

**答案**：
- **A**：D-葡萄糖 — C₁醛基，C₂—OH右，C₃—OH左，C₄—OH右，C₅—OH右
- **B**：D-甘露糖 — C₁醛基，C₂—OH左，C₃—OH左，C₄—OH右，C₅—OH右
- **C**：D-果糖 — C₁—CH₂OH，C₂=O，C₃—OH左，C₄—OH右，C₅—OH右

**解析**：
成脎反应中，苯肼与糖的C₁（醛基或α-羟基酮基）和C₂反应形成脎（osazone），**C₁和C₂的构型信息在成脎过程中丢失**。因此：

- 所有C₃、C₄、C₅构型相同而仅C₁、C₂不同的糖会生成**相同的脎**
- D-葡萄糖、D-甘露糖、D-果糖这三种糖的C₃、C₄、C₅构型完全相同（都具有D-赤藓糖型C₃-C₅），仅在C₁和C₂上不同：
  - D-葡萄糖：C₂—OH在右（费歇尔投影式）
  - D-甘露糖：C₂—OH在左
  - D-果糖：C₁为—CH₂OH，C₂为酮羰基（=O）
- 三者与过量苯肼反应均生成**D-葡萄糖脎**（黄色结晶）

费歇尔投影式（从上到下C₁→C₆）：
```
D-葡萄糖：          D-甘露糖：          D-果糖：
CHO                 CHO                 CH₂OH
H—C—OH              HO—C—H              C=O
HO—C—H              HO—C—H              HO—C—H
H—C—OH              H—C—OH              H—C—OH
H—C—OH              H—C—OH              H—C—OH
CH₂OH                CH₂OH                CH₂OH
```
